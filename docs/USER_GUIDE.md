# Skiba Tables User Guide

Use the visual by assigning row and value fields in the Power BI field wells. Search initially covers loaded rows. When more data is available, use Search Full Dataset to request remaining segments and wait for the distinct progress message.

Use column filters and the existing toolbar actions according to the report author’s configuration. Export availability depends on the report permission policy. A no-export viewer may inspect data but cannot create CSV, Excel, or PDF exports under the approved policy.

For accessibility, use keyboard focus, Enter, and Space on controls and confirm high-contrast behavior in the host report. If a report is refreshed or reopened, saved views should be parsed defensively even when older fields are absent.
